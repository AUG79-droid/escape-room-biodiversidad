Instrucciones obligatorias

El panel ha fallado. Tu razonamiento es la clave para recuperarlo.

Una decisión de proyecto simulada ha fragmentado la visión de sostenibilidad en diez sistemas conectados. Recupéralos en orden. Cada sala revela una pista y desbloquea una explicación técnica. Combina las pistas para introducir el código final de recuperación.

Cómo jugar

  1. Entra en la Sala 1. Las posteriores permanecerán bloqueadas.
  2. Completa todos los campos y valida tu respuesta.
  3. Cada sala permite cinco intentos completos; las respuestas incompletas no cuentan.
  4. Tras el quinto intento incorrecto se revela la solución y la ruta de aprendizaje continúa.
  5. Lee cada explicación, reúne las diez pistas e introduce el código final.

El progreso se guarda en este navegador. No existe penalización por tiempo: el cronómetro solo registra la duración.
